- AlgorithmsTesting - C++ applications used to test some of the functionalities implemented in NDS-drivers. 
- DANDataGenerator - test NDS-Driver to Generate Data that will be archived with nds-dan driver. 
- DANDrivers - nds-dan drivers.
-       OscilDANCP - nds-dan driver for oscilloscope mode.
- DataAgregator - test NDS-driver used to agregate all the Count Rates produced in Data Generator NDS-driver
and to calculate measurement parameters with ML-model.
- DataGenerator - test NDS-driver used to generate all the Count Rates.
- include - general for multiple drivers include files 
- nds-dan - source files to compile nds-dan library.
- nds-oscilloscope - nds-driver for oscilloscope mode.
- nds-sdn-oscil - nds-sdn driver for oscilloscope mode.
- nds3-6683h - nds-driver support for 6683h board.
- nds3-5763 - nds-driver support for NI5763 board.
- nds3-ni5772 - nds-driver support for NI5772+7976R board. 
- nds3-sdn - nds-driver support for sdn interface. 
- onnxruntime-linux - support library for ML-integration. 


- nds3-receiver - test driver for receiving CountRates (Temperatures) from another PCFs
- nds3-sender - test driver for sending Countrates (Temperatures) to another PCFs.
(These two drivers should be tested on different machines).
